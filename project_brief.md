# My agent: travel-concierge
One-liner: A conversational agent that helps travelers discover, plan, and manage luxury travel destinations with a catalog of curated places.

Tool coverage:
- Memory: Remembers traveler preferences (preferred climate, budget, dietary needs, past trips)
- Tools: Search destinations by city/category, view destination details, and add new destination recommendations to Firestore
- Catalog/UI: Curated travel destinations collection rendered as structured cards and tables
- Image gen: Generates custom destination landscape visuals
- Sandbox: Computes trip budgets, daily itinerary costs, and currency conversions

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for trip budget calculations, Cloud Trace
